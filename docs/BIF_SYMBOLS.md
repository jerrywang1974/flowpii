# BIF 符號詞典（FlowPII）

詳見程式內 `src/flowpii/symbols.py` 與計畫中的對照表。

## Excel 自動填寫欄位（MVP）

| 欄 | 意義 | 來源 |
|---|---|---|
| A | 檔案編號 | 頁首編號 |
| B | 作業流程名稱 | 頁首流程名 |
| G | 檔案名稱 | `C:` → 藍區資產 |
| H | 檔案型態 | `(D)`/`(P)` |
| AF | 資料來源 From | 箭頭起點 |
| AG | 接收單位 To | 箭頭終點 |
| AH | 傳輸方式 | `A:` 動作 |

其餘法遵欄位由 PII 管理者於 Excel 補齊。
